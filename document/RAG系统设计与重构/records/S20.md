### API 契约锁定（实现前置， invariant #7）

以当时 TypeSafe **官方一手文档**交叉确认（4 页），Jev 精确 API 契约由 `STRONG_INFERENCE` 升级为 `CONFIRMED`；未凭博客示例实现：

- `docs.typesafe.ai/api/system-one`：`POST https://api.typesafe.ai/v1/systemone`，`Authorization: Bearer <key>`；请求 `{model, state, questions}`，响应 `{model, answers, usage}`。
- `docs.typesafe.ai/primitives`：`Noul→noul(0-1)`、`Score→score(ordinal)`、`Choice→choice`、`Box→box`；经 question 的 `type`+`instructions` 声明。
- `docs.typesafe.ai/primitives/noul`：Noul 为 yes/no 判定，返回"答案为 yes 的概率"∈`[0,1]`；`type:"noul"`、`instructions`、可选 `criteria{true,false}`；响应 `noul` float 0-1，**无独立 confidence 字段**。
- `docs.typesafe.ai/introduction/quickstart`：逐字样例 `{"state":"...","model":"jev-latest","questions":{"is_urgent":{"type":"noul","instructions":"..."}}}` → `{"type":"noul","noul":0.99}`；SDK `client.system_one(state=t, questions={"is_urgent": Noul(instructions="...")})`，读 `response.nouls["is_urgent"].noul`。

关键选型：**Noul 概率∈[0,1] 直接作归一化相关性分数**（无需额外归一化），优于 ordinal `Score`（需标定）。适配层只认 `answers.{q}.noul`，上层只认归一化分数，隔离供应商字段。

## P3：Jev 出境门控与降级链路集成验证（2026-11-11）

### 降级集成 seam（CODE_CONFIRMED，真实异常类型）

- `RagToolsClient.rerank()`（`RagToolsClient.java:74-81`）用 `.retrieve().body()`，**不 catch/包装**（区别于 parseDocument/buildRaptor）；Python `/rerank` 返回 503 时 Spring 默认状态处理器抛 `HttpServerErrorException.ServiceUnavailable`（`RestClientResponseException`⊂`RestClientException`⊂`RuntimeException`）。
- `RagRerankService.rerank()`（`:76-88`）catch `RuntimeException`→`TransportResult.failedAfter(sourceWindow, ledger, transportReason(ex), TRANSPORT, List.of(), errorMessage)`；`transportReason`（`:218-231`）走 getCause，`ServiceUnavailable` 非 Cancellation/Interrupted/Timeout 且 simpleName 不含 "timeout"→`TRANSPORT_ERROR`；`attempted=true`、`success=false`、`resultCandidates` 空、fusion 候选保留。
- `RagRetrievalEngine.executeRerank`（P1 已冻结）失败→`markPolicyRerankStatus(FAILED)` 移除 score/rank、`markUsedChannel("rerank")`、`log.warn` 保留 weighted-hybrid（`:897`）、加 note、exchange 继续、final selection 单次、references/O9 守恒。
- 结论：Jev fail-closed（无 key/不可用/超时/契约不符）→Python 503→`TRANSPORT_ERROR/TRANSPORT/FAILED_AFTER_REQUEST`→现有 weighted-hybrid 兜底，**Java 权威零改动**即满足降级语义。
