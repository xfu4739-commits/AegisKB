## 必须保留的边界

- Java 是 RAG 业务主链路，Python 是算法工具箱。
- 一个业务决策只有一个权威；`RetrievalPlan` 只解释一次 scope/channel/预算/排序特征，SAG 循环只新增"调用时机与查询文本"自由度。
- final selection 每次 exchange 只执行一次（阶段2对合并窗口）。
- 最终答案只能由阶段2 manifest 渲染 + 生成产出；循环内模型文本不作为 answer。
- Source Evidence 与 Context Only 硬分池；web 结果仅 Context Only，无 `[n]` 资格。
- 最终 citation 只由答案合法 ASCII `[n]` 绑定同轮 rendered/reused Source。
- 真实上传、重建、初始化、聊天和外部数据出境默认由用户执行（S19 的真实操作授权不延续到 S20）。
- S20：Jev 只产归一化分数特征，不获得任何业务权威；默认 cross-encoder 零变化；出境需用户授权+key；失败降级 weighted-hybrid；可逆无 facade。
- 模式决策不新增业务词、词表、文档名或 contains 规则。
