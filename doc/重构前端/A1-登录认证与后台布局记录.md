## 文件职责与数据流

- `src/shared/auth/session.js`：唯一 token/用户名键、已确认 profile、认证状态与会话代次；只让当前代次安装 profile 或清理 token。跟踪并在退出/身份切换时取消认证请求。
- `src/shared/auth/adminAuth.js`：登录、`/me` 确认、并发检查合并、退出、登录取消；拒绝迟到登录/资料覆盖，旧退出失败不能污染新登录或阻止新账户退出。
- `src/shared/api/http.js`：Bearer、JSON envelope、30 秒 JSON 超时、显式取消、错误类型、401/403、multipart、Blob 和 SSE。认证失效不在 HTTP 内强制跳转，由路由层决定；公共聊天不被重定向到后台登录。
- `src/router/adminGuard.js`：受保护路由、服务端确认、安全回跳、跨标签页 storage 变化和会话失效回登录。回跳只允许已注册且可返回的内部后台路径，拒绝外部/协议相对地址、反斜杠/控制字符、登录循环及未知路径。
- `src/router/index.js`：注册懒加载后台路由。公共聊天只加载其自身页面，后台页面不进入聊天首屏请求。
- `src/features/admin/shell/AdminFrame.vue`：局部 Ant ConfigProvider 与独立弹层宿主；主题只影响后台子树，不使用全局 Ant class 覆盖。
- `AdminLoginView.vue`：空白凭据表单、验证、密码可见切换、提交锁、错误与登录取消。密码只在页面内存里使用，离开/成功后清理，不加入 URL 或持久化状态。
- `AdminShell.vue`、`AdminNav.vue`：响应式布局、可用导航、折叠/抽屉、面包屑、用户名、退出确认和焦点。
- `AdminAccountView.vue`、`AdminAccessView.vue`、`AdminNotFoundView.vue`：当前账户、认证故障处理、后台未找到页。
- `admin.css` 与新增 `--admin-*`：后台样式与语义 Token。没有改变第一阶段任何已有 Token 的值。局部 `colorTextDescription` 修正组件默认面包屑对比度。
- `src/features/chat/chatApi.js`：保留原公开方法、字段、字符串分页、SSE 消费器和返回结构，仅将重复 HTTP/认证实现替换为共享客户端。

数据流：用户提交 → login 获取 token → 同轮 `/me` 确认 → 当前代次安装用户名 → 路由进入后台。HTTP 401 只清理其发起时的当前代次，守卫才决定是否回登录。403 保留 token 并明确显示无权限；失败和重试都不猜造 profile。新凭据/退出使旧请求失去所有权，旧响应不能恢复资料。

## 测试闭环与发现

### 先冻结聊天协议

在原聊天 API 测试中补充六种调用的 wire fixture，以及“旧 token 的 401 晚于新登录”的目标测试。原实现运行 10 项，9 通过、1 失败，证实旧 401 会删除新 token。切换共享客户端后 10 项通过；不是把未实现测试或缺模块当作产品红灯。

### 新认证/传输目标

- `/me` 才能建立 profile、并发确认只请求一次、无效 profile 拒绝、失败登录不覆盖现有凭据、防重复提交。
- 连接错误/403 保留凭据但不展示未经确认的 profile；过期 JWT 可快速拒绝，其他凭据仍交服务端验证。
- 退出取消已认证请求；迟到 `/me`/login 不能复活退出状态；同字符串 token 的新代次也隔离；旧退出结果不影响新登录或其退出。
- multipart 保留 file/meta 且由浏览器设置 boundary；JSON 文件也是合法 Blob 下载，不能误拆成 code/data；超时与用户取消区分。
- 流式请求继续交既有 SSE 消费器，事件回调需属于当前会话代次；上层生成/停止/卸载与引用规则不改。

新测试曾暴露两个实现问题：旧 logout 错误污染新登录提示、JSON 产物下载误走 envelope。修正代次检查及 Blob 分支后转绿。

## Vue 学习点

1. **路由守卫**在进入后台前确认服务端登录态；公共聊天不会执行后台鉴权。路由按已实现页面懒加载，视图只负责展示。
2. **reactive/ref** 保存当前登录状态与表单；composable/服务协调请求。每次身份变化递增代次，响应到达时检查自己是否仍拥有写状态的资格。
3. **provide/inject 与 ConfigProvider**把后台主题和弹层容器传给子组件，避免与聊天主题混用。弹层有独立 DOM 宿主，路由卸载时不会混淆视图与浮层的 DOM 所有权。
4. **props/emits**让同一个导航用于桌面和手机；按钮发出导航事件，由布局决定关抽屉和恢复焦点。
