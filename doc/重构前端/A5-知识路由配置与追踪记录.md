## 本轮补齐与学习记录

- `routeState.js`：URL 是知识库、分类、范围、主题、搜索、页码及画像文档选择的唯一展示状态；浏览器返回会恢复筛选。切库清空选择与编辑器，取消旧请求代次。局部加载列表每页 20 条；文档仍明确为全局前 200 条中的当前库集合，不伪装服务端全库分页。
- 范围/主题详情折叠，关联可筛选、保存、编辑和移除；重建已加载与选中集合分别确认，展示完整 ID 集合。表单保留父范围、别名、示例、排序、回答结构、执行偏好及关联分数/来源/原因。操作人不预填。写入失败保留草稿与操作人，确认提交禁用重复操作，离页拒收旧回调。
- `TraceDetails.vue`：范围/主题/文档候选依原序展示，保留 0 分数和字符串 ID；坏 JSON 只显示格式诊断。缺失/未知状态不会默认为失败。候选可到新版文档，轮次来源明确链接旧版会话；A6 尚未实现，不提前注册占位路由。
- `CODE_CONFIRMED`：当前 `KnowledgeRouteTraceItemVo` 不含耗时、channel 或实际执行 route 字段；页面显示“未记录”，不从 mode、score 或 errorMsg 猜测。所有原始字段可折叠查看，没有改变后端投影或业务决策。
- Vue 学习点：computed 从 URL 投影筛选，watch 只响应请求参数；独立 read resource 用代次与 AbortController 拒绝旧响应。编辑表单与确认请求分开，确认使用对象快照；焦点在弹层打开时进入，关闭后恢复原触发按钮。
