## 本步内容与学习点

- `src/features/admin/dashboard/overviewApi.js` 仅封装三个现有读取接口；没有新增后端接口或写动作。
- `overviewModel.js` 用纯函数整理展示数据：文档总量与返回样本分开；未知路由状态不归入失败；缺失值显示 `—`，真实零保留；成功率变化按百分点，置信度保留小数，耗时转换 ms/s/m；无可比窗口不显示环比。
- `overviewState.js` 管理 loading/data/error、取消与请求序号。同一窗口刷新失败保留并明确标记旧数据；切换窗口清空旧结果，晚到请求不能覆盖新结果。`onBeforeUnmount` 释放请求所有权。
- `AdminDashboardView.vue` 并行读取文档和路由；一个失败不掩盖另一个，局部可重试。显示文档样本、处理状态和路由样本口径。
- `AdminQualityOverviewView.vue` 将时间窗写入 URL；展示聚合指标、路由趋势、检索通道、路由结果、文档处理耗时。技术口径按需展开，不铺满说明文字。
- `MetricStrip.vue`、`OverviewChart.vue` 是接收 props 的展示组件。原生 SVG 保留曲线缺口，避免把缺失值补零；详细值有表格等价信息，指标小图可用键盘打开数据 Modal。
- 导航只新增已经实现的两个入口；旧文档、路由追踪和观测通过明确的“旧版”外链保留，不伪造新版未实现页面。聊天页后台链接仍按原计划保留旧版。
- 配色延续用户确认的蓝灰侧栏、实蓝选中态、白色面板；新增后台指标字号与正向状态 Token，不修改已有聊天 Token 的值。

数据流：URL 时间窗 → 请求快照/AbortSignal → 现有共享认证运输层 → 纯函数投影 → computed 指标与图表。这里可学习 Vue 的 `computed`、`watch`、`ref`、组件 props/事件和卸载清理；页面不负责重新解释 route 或 citation。

## 自动验证中的发现与修正

1. 第一轮 A2 Chrome 11 项中 5 通过、6 失败。时间窗控件缺少必要 ARIA 属性，未展开时引用不存在的选项；耗时定义列表把说明放在 dd 外，违反 dl 语义。窗口测试还暴露点击被选择项覆盖的问题。四个固定时间窗采用与主题一致的原生 select，保留标签、键盘与 URL 同步；耗时次数移入 dd。
2. 新增身份切换用例先得到红灯：`npm run test:e2e -- admin-overview.spec.js --project=chrome --grep "changing identity"` 退出码 1；等待新身份 `/me` 时，断言要求旧指标数量为 0，实际仍有 4 个。将受保护 RouterView 与已确认会话状态绑定；身份变化立即卸载旧数据组件，确认成功后重新读取。修正后该用例通过。
3. 修正后的第二轮 Chrome 为 11 通过、1 失败：Ant RadioButton 的原生 input 视觉隐藏，测试直接 check 不能点击；改为点击可见标签并保留 checked 与图表切换断言，不修改产品行为。截图检查同时修正刷新按钮的图标与文字排列。
4. 完整套件首轮 124 项中 122 通过、2 失败；两个动画模式下的同一弹窗检查在遮罩仍动画时读取到混合色，不能据此判断静态 Token 不达标。仅等待 dialog 的 opacity/transform 不够；最终等待局部弹层容器内所有动画完成，再运行 axe。测试随后暴露隐藏数据表中也有“置信度”文字，改为在趋势指标控件范围内定位可见标签。保留颜色与 checked 断言，没有屏蔽 axe 规则或强制点击。

以上为新实现的验证过程，不把测试定位方式问题记为后端或旧产品缺陷。
