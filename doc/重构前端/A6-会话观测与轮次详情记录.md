## 文件职责与数据流

代码集中 `vue-next/src/features/admin/observability/`，保留旧版不动。

- API 只封装上述接口；Model 负责已知查询字段、状态文本、原身份/原编号及表格定位参数，不推断路由、证据或引用。
- List → Session → Exchange 三级懒加载路由：URL 保存列表条件/页码/返回锚点及轮次页码；会话和轮次包装组件以参数 key 划分生命周期。
- Session monitor 串行等待上次请求结束，running=false、失败、暂停或离页停止调度，代次拒收迟到结果。摘要重建单独确认当前 conversationId，失败保留旧摘要，提交禁重复。
- Exchange 独立读取 session/detail，答案可从成功的会话快照读取；检索与通道仅在进入对应分类时并行请求，基准只在 Prompt 分类读取，同一对象标签往返不重复加载。
- Markdown 复用新版已测试的清洗与代码复制组件；观测答案不把 token 猜成来源按钮，来源列表只使用后端返回的稳定 citationIdentity 和合法原 referenceId。Context Only 单列；预算/绑定/归档快照按后端事实展开，不按下标拼接来源。
- Modal 展示候选、阶段与来源元数据，恢复原按钮焦点；表格命中链接保留原文档/task/table/行/列/单元格参数。

Vue 学习点：computed 从 URL 投影查询；key 划分实体所有权；composable 管理 AbortController/请求代次与定时器；局部 read resource 隔离失败；确认对话框的状态与实际写请求分离。
