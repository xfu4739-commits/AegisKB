## 3. 协议审计

### producer → transition → consumer

- producer 为既有 Java API。A0 不改它、不猜字段；前端事实来自 `vue/src/api/api.js` 与调用页/测试。
- transition 为 API envelope、认证头、manage 数字转换、页面纯函数与表单投影。
- consumer 为表格 rowKey、路由 ID、任务轮询游标、配置表单和具体写动作。UI 更换不能另立业务 authority。

### 已确认协议

- `CODE_CONFIRMED`：成功 envelope 接受 code `0`；一般超时 30 秒；token 键为 `aegis-kb-admin-token`、用户名键为 `aegis-kb-admin-user`，Bearer 放请求头。
- `CODE_CONFIRMED`：`/admin/auth/me` 为 GET，其余清单接口为 POST。登录/退出和业务写入单列，不纳入只读截图许可。
- `CODE_CONFIRMED`：多数管理请求调用 stringifyManageValue，递归转 number/bigint，保留 string、boolean、null；列表和页码按该实际 wire 类型迁移。配置五个 wrapper 直接使用 payload/空对象，不经过递归转换。
- `CODE_CONFIRMED`：上传 FormData 含 `file` 和 application/json Blob `meta`（documentName/operatorId/knowledgeBaseId）；不要手工设置 boundary。下载返回认证 Blob，含文件名处理；不得用 token 查询参数绕过。
- `CODE_CONFIRMED`：实体 ID 是字符串，不能 Number 化；任务/引用身份、表格定位和来源顺序由接口决定。

## 5. 学习与数据流

- 路由负责“打开哪个对象/页面”，不会因更换组件库而改变接口含义。页面容器负责组合数据和交互；展示组件只收 props 和发 emits。
- composable 是可组合的状态逻辑：持有请求代次、取消句柄、加载/错误与草稿；离开页面就结束其所有权，防止迟到响应覆盖新选择。
- API 模块只做认证、序列化和协议转换；表格 computed 只投影真实数据，不推断业务结论。
- A0 的静态 HTML 只用于确认视觉。A1 起实现 Vue/Ant Design Vue 组件，不把草案里的禁用按钮、演示指标或导航占位搬入生产。
