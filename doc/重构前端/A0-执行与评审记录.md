## 发现与后续归属

- A1：旧本地 JWT 守卫不能代替 `/me`；共享认证需处理晚到 401、安全回跳和公共聊天不跳转。旧测试对固定口令的预填要求不迁移。
- A3 首次写之前：operatorId 的来源需核实，当前旧页面常量不能冒充登录身份。没有服务端证据前不猜用户 ID。
- A4：已用长 ID fixture 复现旧日志游标 Number 转换丢精度；新游标与排序须保持字符串身份并先建立目标测试。
- A5：旧画像批量动作基于全局第一页 200 条后筛当前库的已加载集合。必须显示实际对象集合，不能直接命名为全库重建。
- A7：配置接口保留原始 JSON 类型，不同于多数 manage 请求的数字字符串转换；保留 expectedVersion、changeNote 和恢复新增历史语义。
- 未发现必须在 A0 扩大后端范围的证据；真实认证字段、任务终态和冲突错误体在所属步骤核对。所有真实写操作仍由用户执行。

## 本步学习点

路由定义页面与对象身份；API 模块转换运输协议；composable 持有请求和草稿生命周期；展示组件通过 props/emits 协作。重写组件布局不改变业务 authority。A0 先建立这些边界，避免把旧大组件原样搬进新版。
