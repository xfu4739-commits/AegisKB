## 页面与职责

新增 `/admin/documents/:documentId`。文档列表和上传结果改为新版详情链接，并保留列表关键词、页码、条数；文档详情在导航归入“文档管理”。旧前端保持独立可用。

- `AdminDocumentView.vue` / `DocumentWorkspace.vue`：文档参数拥有页面实例，切文档卸载旧组件；首屏只读取文档摘要，技术元数据折叠。标签页异步加载，URL 保存 section、任务和定位；任务身份变化重新建立子页所有权。
- `documentApi.js`：仅封装原有读取、策略确认、构建与认证下载；数字/stepNo 转 wire 字符串，ID 不 Number 化，boolean 保持布尔。所有请求经过 A1 共享认证运输层。
- `documentState.js`：读取资源复用已测的请求代次与 AbortController；任务轮询在前次请求结束后调度，终态/错误/卸载停止，不堆积并发。只继续同一文档/任务，拒绝返回身份不匹配。
- `documentModel.js`：长日志 ID、合法流水线、有序 steps、提交前置条件、既有表格深链接投影、安全 Markdown 与受控图片类型。没有根据前端相似度或原因字符串决策检索/引用。
- `StrategyPanel.vue`：查看推荐方案，配置父/子切块流水线、调整顺序、修改说明和显式操作人 ID；二次确认文档/方案/动作，失败保留，重复提交锁，脏方案禁构建。没有“确认后自动构建”。
- `TaskPanel.vue`：解析/构建任务、指定或最近任务、阶段/错误/时间、增量日志、历史日志分页、读取重试与暂停自动刷新。读取不是重跑任务；进入旧任务不等于重新触发解析。
- `ArtifactPanel.vue`：原有产物清单、内容/Markdown/JSON 预览、内容搜索/复制、JSON 格式化及路径匹配、长内容展开和认证下载。路径匹配展示上限 50 条、深度 20，明确作为预览边界；下载与复制仍取接口原文。安全图片生成 Blob URL，关闭/卸载释放；其他类型不当作可执行页面打开。JSON 下载仍为文件，不误判为 API envelope。
- `ChunksPanel.vue`：服务器分页、分块正文/定位/向量状态、父块详情及同父块导航。原始 ID 与 task scope 保持；切页/切对象拒绝迟到数据。
- `ParsePanel.vue`：处理指标/流水线、快照样本、解析诊断、告警、页索引、图层类型、原图与 bbox 选中定位、表格高亮。保留 highlightTableId/highlightTableNo/highlightRows/highlightColumns/highlightCells 到原请求字段的映射，样本不伪装全量。
- `ExplorerPanel.vue`：按原产物类型搜索与服务器分页，选中节点详情、上/下游或入/出边、关系分页与回退；图谱窗口及等价节点/边列表、缩放和画布滚动；图谱社区/证据；表格行分页和列窗口；RAPTOR 根节点、子分支分页、逐层选择与回退。所有窗口携带 parseTaskId/indexTaskId；没有完整任务身份时不请求虚假的空窗口。
- `Facts.vue` / `ReadState.vue`：按需结构化属性、加载、局部错误和重试，不用一个 JSON 文本框替代深层交互。

展示差异：图谱用有边界的 SVG 和键盘可访问列表，不引入旧图谱依赖；RAPTOR 用层级节点、分支分页与返回路径浏览。页面组织重写，服务端窗口、关系、证据和身份不变。技术对象按需展开，原版入口保留在后台壳。

## 学习记录

数据流：路由 documentId → 独立页面生命周期 → 标签页 read resource → 原 API → 只读投影。策略另建草稿与签名，保存/构建从当前快照生成参数。API 请求快照和页面代次共同决定响应是否仍属于当前选择；关闭预览不等于回滚服务端动作。

Vue 概念：`defineAsyncComponent` 按标签页分块；`:key` 划分文档/任务生命周期；computed 投影与受控草稿；递归组件展示结构化详情；watch/onBeforeUnmount 处理轮询、焦点和 URL 释放。与原版近三千行的单页相比，业务流程各有模块，可分别阅读和验证。
