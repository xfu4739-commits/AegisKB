## 修改与数据流

代码集中在 `vue-next/src/features/admin/catalog/`：

- `catalogSchema.js`：迁移旧页可编辑的检索、通道、权重、切块、GraphRAG/RAPTOR 构建字段和新建推荐初值；不是更改后端算法或全局默认值。
- `catalogModel.js`：草稿、JSON 校验和保存投影。既有配置稀疏项维持未设置；顶层与嵌套扩展项、metadata 保留，非法 JSON 不静默清空。实体 ID 保持字符串。对配置整数、最小值、文件类型和操作人进行输入校验。
- `catalogApi.js`：原有 list/save/delete、文档 page/query/delete/upload；保留默认 30 秒运输超时和 envelope。上传仍为 file + application/json Blob meta，不手工指定 boundary。
- `catalogState.js`：写动作提交锁、错误、AbortController 与卸载保护；失败保留草稿，成功才关闭/刷新。取消请求仅结束前端等待，不承诺回滚服务端已接收的动作。
- `BaseEditor.vue`：基础字段直接编辑；高级参数按需展开，可看完整配置。详情模式只读，可切换编辑。保存失败、取消、焦点恢复与提交中交互分别处理。
- `AdminKnowledgeBasesView.vue`：列表/本地筛选分页、详情、新增、编辑、停用确认。总量由列表本地搜索结果产生，不虚构服务端分页。
- `DocumentUpload.vue`：显式选择知识库、文件与操作人；无单库自动选择，选项加载失败独立重试，文件及表单失败保留。按钮明确“上传并解析”，不将创建任务说成处理完成。
- `AdminDocumentsView.vue`：服务端关键词/分页、URL 恢复、文档状态、删除确认、上传与任务 ID。任务进行中禁删；页末删除回到上一页；旧请求不能覆盖新搜索结果。
- `catalog.css`：仅 admin-next-catalog 命名空间，复用当前 Token；桌面列表、手机摘要，弹窗宽度与局部溢出受控。
- 路由新增 `/admin/knowledge-bases`、`/admin/documents`；导航新增已实现的“知识管理”分组。文档详情归 A4，现有入口明确为外链“旧版详情/旧版任务详情”，不注册伪详情页或自动触发额外构建。

Vue 学习：URL query → computed 筛选条件 → watch 发起读取 → 共享资源处理取消与代次 → 列表投影。编辑从服务端对象复制为独立草稿，子组件绑定草稿，不直接修改列表项；点击保存才序列化发送。原生 select 用于简单选项，Ant Design Vue 提供按钮、Input、Modal、Alert 等。
